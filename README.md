# Tetris для ЛР №3

Восстановлен из листинга лабораторной №5 Сальникова К.С. (страницы 8–24).
Основной проект сохраняет curses, поле 11 × 17, пять фактических форм T/L/S/O/I,
таймер, цвет уровней, пять языков и топ-10 результатов с именем, датой и временем.
J/Z присутствуют в словаре статистики исходной работы, но отсутствуют в block_shapes:
новые формы в реконструкцию не добавлены.

## Запуск Windows
Установите Python 3. Запустите терминал размером не менее 80 × 40.
В папке проекта выполните:
```
py -m pip install -r requirements.txt
py tetris.py
```
Также доступен run.cmd. Стрелки — движение/поворот, пробел — сброс,
p — пауза, h — рекорды, q — выход, Enter — новая игра после проигрыша.
Язык задаётся LANGUAGE в tetris.py (0 EN, 1 RU, 2 DE, 3 FR, 4 IT).
Таймер сохраняет семантику старой работы: показывает время с начала партии,
включая паузы и просмотр рекордов.
